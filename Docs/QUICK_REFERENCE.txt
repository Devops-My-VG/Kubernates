🚀 QUICK COMMANDS
═══════════════════════════════════════════════════════════════════════════════

Preview changes (no changes made):
  ./deploy.sh int plan
  ./deploy.sh qa plan
  ./deploy.sh stg plan
  ./deploy.sh prd plan

Deploy infrastructure:
  ./deploy.sh int apply           # Deploy INT environment
  ./deploy.sh qa apply            # Deploy QA environment
  ./deploy.sh stg apply           # Deploy STG environment
  ./deploy.sh prd apply           # Deploy PRD environment

Destroy infrastructure (IRREVERSIBLE):
  ./deploy.sh int destroy         # Destroy INT environment
  ./deploy.sh qa destroy          # Destroy QA environment
  ./deploy.sh stg destroy         # Destroy STG environment
  ./deploy.sh prd destroy         # Destroy PRD environment
