GitLab Pipeline: Update-Variables Stage - Quick Reference
================================================================================

WHAT WAS ADDED?
================================================================================
New pipeline stage "update-variables" that automatically syncs infrastructure 
details from Terraform outputs to GitLab group variables.

PIPELINE FLOW
================================================================================
validate → plan → apply → update-variables → destroy
           (all stages set to: when: never)

NEW STAGE: update-variables (manual trigger)

ENVIRONMENT COVERAGE
================================================================================
✓ INT  → update-variables:int
✓ QA   → update-variables:qa
✓ STG  → update-variables:stg
✓ PRD  → update-variables:prd

19 VARIABLES UPDATED
================================================================================
AWS Account:
  • AWS_ACCOUNT_ID (from ECR registry ID)

Network & Security:
  • VPC_ID
  • SUBNET_IDS (comma-separated)
  • SECURITY_GROUP_ID

Database (PostgreSQL RDS):
  • DB_HOST
  • DB_PORT
  • DB_NAME
  • DB_USERNAME

Cache (Valkey Serverless):
  • VALKEY_ENDPOINT
  • VALKEY_PORT

  • BACKEND_ECR_REGISTRY
  • BACKEND_ECR_REPOSITORY
  • FRONTEND_ECR_REGISTRY
  • FRONTEND_ECR_REPOSITORY

ECS & Logging:
  • ECS_CLUSTER_NAME
  • CLOUDWATCH_LOG_GROUP
  • ECS_TASK_EXECUTION_ROLE_ARN
  • ECS_TASK_ROLE_ARN

HOW TO USE
================================================================================
1. Run apply job (e.g., apply:int)
   → Creates INT_outputs.json artifact

2. Manually trigger update-variables:int job
   → Extracts terraform outputs
   → Updates 19 GitLab variables via API
   → Uses CI_JOB_TOKEN for authentication

3. Verify variables updated
   → GitLab UI: Settings → CI/CD → Variables
   → OR: glab variable list --project devops8004932/kubernetes/ecs-cluster

TROUBLESHOOTING
================================================================================
Issue: Variables not updating
  → Check job logs: glab ci trace update-variables:int
  → Verify apply:int succeeded and generated int_outputs.json
  → Check GitLab project permissions

Issue: jq: command not found
  → Already in before_script, shouldn't happen
  → Check Docker image (ubuntu:22.04)

Issue: HTTP 401/403 errors
  → CI_JOB_TOKEN issues (rare)
  → Check project settings and CI/CD permissions

Issue: Output values missing or null
  → Terraform apply may have failed
  → Check terraform outputs manually: terraform output -json

MANUAL FALLBACK
================================================================================
If pipeline fails, use manual script:

export GITLAB_TOKEN="glpat-xxxx"
bash SETUP_GITLAB_VARIABLES.sh
