================================================================================

STEP 1: Create AWS IAM User (One-time)
──────────────────────────────────────
1. Go to AWS Console → IAM → Users → Create User
2. Username: ecommerce-app-deployment
3. Attach policies:
   - AmazonEC2ContainerServiceFullAccess
   - AmazonEC2ContainerRegistryFullAccess
4. Generate Access Key ID and Secret Access Key
5. Save safely (used for AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY)


STEP 2: Collect Infrastructure Details
───────────────────────────────────────
Run the automatic collection script above:
./collect-gitlab-inputs.sh

Copy all output values


STEP 3: Generate Application Secrets
──────────────────────────────────────

  Command: openssl rand -base64 32
  Output: Use this for JWT_SECRET variable


STEP 4: Open GitLab Project Settings
───────────────────────────────────
1. Go to GitLab → Your Project
2. Settings → CI/CD → Variables
3. You'll see existing variables (if any)


STEP 5: Add Each Variable to GitLab
──────────────────────────────────
For each variable:
  1. Click "Add Variable"
  2. Key: [Variable name from checklist]
  3. Value: [Value from collection script or manual input]
  4. Protected: ✅ Check (for all)
  5. Masked: ✅ Check (only for: AWS_SECRET_ACCESS_KEY, DB_PASSWORD, REDIS_PASSWORD, JWT_SECRET, EMAIL_PASSWORD, GOOGLE_CLIENT_SECRET)

Repeat for all 20+ variables


STEP 6: Verify Variables
──────────────────────────
1. Go to CI/CD → Pipelines
2. Push code to trigger pipeline
3. Monitor pipeline execution in GitLab UI
4. Check CloudWatch logs for deployment status


STEP 7: Verify Application
──────────────────────────
1. Get ALB DNS: aws elbv2 describe-load-balancers --region us-east-1 --profile $AWS_PROFILE --query 'LoadBalancers[0].DNSName' --output text
2. Open: http://[ALB_DNS]
3. Application should be running ✅

3. Build stage: Compiles code, runs tests
4. Push stage: Builds Docker images, pushes to ECR

✅ VERIFICATION COMMANDS (After Deployment)
================================================================================

Check ECS service:
  aws ecs describe-services --cluster ecs-cluster-int --services ecs-cluster-int-httpd-service --region us-east-1 --profile $AWS_PROFILE

  aws ecs list-tasks --cluster ecs-cluster-int --region us-east-1 --profile $AWS_PROFILE

View logs:
  aws logs tail /ecs/ecs-cluster-int --follow --profile $AWS_PROFILE

  aws elbv2 describe-load-balancers --region us-east-1 --profile $AWS_PROFILE --query 'LoadBalancers[0].DNSName' --output text
